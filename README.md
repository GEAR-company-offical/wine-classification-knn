# Классификация сортов вина (kNN)

Учебный ML-проект: многоклассовая классификация сортов вина по химическим признакам.

## Задача

По 13 химическим признакам вина (алкоголь, магний, фенолы и т.д.) определить его сорт.  
Тип задачи: **многоклассовая классификация** (3 класса).

## Данные

Встроенный датасет `sklearn.datasets.load_wine`:
- 178 объектов
- 13 числовых признаков
- 3 класса (сорта вина)
- Пропусков нет

## Что сделано

1. **EDA:** проверка пропусков, типов данных, распределения классов, визуализация (гистограммы, boxplot).
2. **Train/test split:** 70/30, `random_state=8` для воспроизводимости.
3. **Базовая модель:** обучен kNN с разным числом соседей (k = 1, 3, 5, 10, 15, 25) без масштабирования.
4. **Проблема:** признаки в разных масштабах (`alcohol` ≈ 11–15, `magnesium` ≈ 70–162) → kNN работает плохо (accuracy ≈ 0.59).
5. **Решение:** применён `StandardScaler` (fit только на train).
6. **Результат:** accuracy выросла до **0.70**.
7. **Сравнение:** построена таблица «до/после масштабирования».

## Результаты

**Ключевой вывод:** масштабирование признаков критично для методов, основанных на расстояниях (kNN). Без него один признак доминирует и модель фактически игнорирует остальные.
